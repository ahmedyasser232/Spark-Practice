# Apache Spark Practice

This repository contains practical exercises in **Apache Spark and PySpark**, focusing on distributed data processing and data analysis.

## Topics Covered

- **RDDs:** Transformations, actions, `map()`, `filter()`, and `reduceByKey()`.
- **DataFrames:** Data manipulation, filtering, grouping, and aggregations.
- **Spark SQL:** Writing SQL queries for data analysis.
- **Lazy Execution:** Understanding transformations, actions, and execution plans.
- **Data Processing:** Handling missing values, removing duplicates, and performing joins.
- **Performance:** Exploring distributed computing and efficient data processing.

## Technologies Used

- Python
- Apache Spark
- PySpark
- Spark SQL
- Jupyter Notebook / Google Colab
